# تحليل البيانات باستخدام Pandas 🐍📊

مستودع كورس **احترف تحليل البيانات باستخدام Pandas**، بشرح عربي يغطي العمليات الأساسية للتعامل مع البيانات في Python، من قراءة الملفات وتنظيف البيانات إلى تجميعها ودمجها وعرضها بصريًا.

يمكنك استخدام المستودع للتطبيق مع الفيديو، ومراجعة الأكواد، وتجربة العمليات على بياناتك الخاصة.

## 🛠️ المتطلبات

قبل البدء، تحتاج إلى:

- Python 3
- مكتبات `pandas` و`matplotlib`
- بيئة لتشغيل الأكواد، مثل Jupyter Notebook أو VS Code

لتثبيت المكتبات:

bash
```
pip install pandas matplotlib
```
